# 术语表

## 概述

本术语表定义了《打印机维护手册》中使用的术语。它是为指定的打印机操作员、IT支持人员和完成服务日志条目的人员编写的。定义描述了通用办公打印设备。特定型号的零件名称、更换间隔和错误代码在制造商的服务手册中有记录，该手册始终优先于本指南。术语按主题分组，以便相关概念一起出现。缩写形式列在缩写部分。

---

## 硬件组件

### 图像和融合

| 术语 | 定义 |
|------|------------|
| **鼓单元** | 接收潜像并将墨粉转移到纸张上的光敏圆柱。在许多激光打印机中，它是一个单独的可更换消耗品。 |
| **融合单元** | 在压力下将墨粉熔化到纸张纤维中的加热滚筒组件。它达到很高的工作温度，在维护之前必须完全冷却。 |
| **传输带** | 将墨粉图像从成像鼓传输到彩色激光打印机纸张上的带子。 |
| **传输滚筒** | 将电荷施加到鼓上，从而将墨粉从鼓上拉到纸张上的滚筒。 |
| **电晕线/充电滚筒** | 在曝光前对鼓施加均匀静电电荷的组件。脏污或损坏的电晕线会导致条纹和密度不均。 |
| **激光扫描单元** | 使用激光束将潜像写入鼓的光学组件。其窗口上的灰尘会产生褪色或重复的缺陷。 |
| **显影滚筒** | 在显影过程中将墨粉输送到鼓的滚筒。 |
| **臭氧过滤器** | 捕获由高压充电组件产生的臭氧的过滤器。强烈的持久气味可能表明过滤器或电晕线存在问题。 |
| **废墨粉容器** | 在清洁过程中从鼓中移除多余墨粉的容器。在装满之前更换它。 |

### 纸张路径和进纸

| 术语 | 定义 |
|------|------------|
| **拾取滚筒** | 从纸盒中抬起顶部纸张并将其送入纸张路径的滚筒。磨损或光滑的滚筒是最常见的进纸错误原因。 |
| **分离垫** | 摩擦垫，仅保留顶部纸张，防止一次进纸多张。 |
| **进纸滚筒** | 将纸张沿从纸盒到输出托盘的路径移动的滚筒的通用术语。 |
| **对齐** | 纸张和对每个颜色层的对齐。对齐不良会产生倾斜的纸张或颜色边缘。 |
| **双面打印单元** | 将纸张翻过来进行双面打印的机构。 |
| **自动文档进纸器（ADF）** | 将原始文档送过扫描玻璃进行复制或扫描的托盘，这样就不需要一次放置一页。 |
| **输出托盘** | 接收完成页面的容器。满载的托盘会导致出口处发生卡纸。 |

## 消耗品和用品

| 术语 | 定义 |
|------|------------|
| **消耗品** | 在正常操作过程中用完并在计划内更换的任何物品，例如墨粉、墨水、鼓和废墨粉容器。 |
| **OEM用品** | 由打印机制造商制造的墨盒和零件。兼容（第三方）用品是新制造的替代品；再制造或加墨的墨盒都不是。 |
| **墨粉输出量** | 墨盒的估计页数，通常以标准页面的5%覆盖率进行评级。密集的图形会降低实际输出量。 |
| **维护套件** | 包含磨损件的捆绑包，通常包括融合滚筒、传输滚筒、拾取滚筒和分离垫，在设定页码间隔时一起更换。 |
| **读数** | 打印机报告的总页数。每天记录它以跟踪使用情况并计划预防性维护。 |
| **保质期** | 未开封的消耗品在按指示存储时保持规格的期限。 |

!!! note "输出量是估计值"
    当作业包含全页图形或照片时，额定为2,000页的墨盒打印的页面数要少得多。使用读数和观察到的打印质量，而不仅仅是额定输出量来计划更换。

## 打印质量术语

| 术语 | 定义 |
|------|------------|
| **幽灵影** | 在页面下方出现图像的淡影，通常由鼓或融合单元未完全释放墨粉引起。 |
| **条纹** | 横跨页面的重复明暗条纹，通常与传输带或颜色校准有关。 |
| **条纹** | 在进纸方向上运行的连续线条。黑色条纹通常指向鼓或墨盒；白色条纹指向墨粉堵塞。 |
| **重复缺陷** | 在固定间隔重复的标记。间隔与故障滚筒的周长相匹配，有助于识别组件。 |
| **褪色** | 整体打印密度变浅或不均匀，通常由低墨粉、潮湿纸张或墨粉节省模式引起。 |
| **模糊** | 打印后墨粉擦掉的墨粉，表明融合单元未将墨粉粘合到纸张上。 |
| **颜色校准** | 控制面板程序，用于对齐颜色层并校正密度。在更换硬件之前运行它以解决颜色投诉。 |

## 纸张和介质术语

| 术语 | 定义 |
|------|------------|
| **介质** | 通过打印机的任何材料，包括普通纸张、信封、标签和透明胶片。 |
| **基础重量** | 以g/m²（gsm）表示的纸张重量。超出打印机支持范围的介质会导致卡纸和融合不良。 |
| **纤维方向** | 大多数纸张纤维对齐的方向。它影响卷曲和纸张沿路径的平稳度。 |
| **双面进纸** | 两个或多个纸张一起进入纸张路径，由静电、潮湿纸张、磨损的分离垫或过满的纸盒引起。 |
| **进纸错误** | 无法拾取纸张或以角度进入的纸张。 |
| **卡纸** | 在纸张路径内停止的纸张。在清除卡纸后，始终检查撕裂的碎片。 |
| **激光安全介质** | 经过评级可承受融合温度的介质。喷墨涂层和照片介质可能在激光打印机内部熔化。 |

## 网络和软件术语

| 术语 | 定义 |
|------|------------|
| **打印驱动程序** | 将文档转换为打印机页面描述语言并将其发送到设备的软件。 |
| **打印队列** | 从操作系统可见的等待打印机的有序作业列表。 |
| **静态IP地址** | 分配给打印机的固定网络地址。不断变化的DHCP地址会中断驱动程序连接并使打印机看起来处于离线状态。 |
| **配置页面** | 从控制面板打印的报告，列出了IP地址、固件版本、安装的选项和供应状态。 |
| **固件** | 嵌入在打印机中的软件。按计划的时间表更新它，而不是在营业时间更新。 |
| **扫描到电子邮件/扫描到文件夹** | 将扫描的文档发送到邮箱或网络共享的功能，无需连接计算机。 |
| **页面描述语言** | 用于描述页面到打印机的格式，例如PCL或PostScript。不匹配的驱动程序会产生混乱的输出。 |

## 维护和服务术语

| 术语 | 定义 |
|------|------------|
| **预防性维护** | 在故障发生之前进行的计划工作，例如深度清洁和维护套件更换。 |
| **服务日志** | 记录单个打印机的检查、读数、更换的零件和事件的记录。参见[首页](index.md)中的模板。 |
| **资产记录** | 标识打印机的库存条目，包括型号、序列号、位置和保修或合同状态。 |
| **升级** | 从常规操作员维护到IT支持或合格技术人员的移交。参见[故障排除指南](troubleshooting.md)。 |
| **服务合同** | 定义响应时间、涵盖的零件和现场支持的协议。在订购零件之前验证覆盖率。 |
| **合格技术人员** | 接受过服务高压或高温组件培训的人员。融合和内部润滑工作仅限于此角色。 |

!!! warning "术语不能代替安全规则"
    上面的几个条目提到了高压或高温组件。在打开任何盖子之前，请阅读[安全指南](safety.md)，并且永远不要在打印机开启时进行维护。
