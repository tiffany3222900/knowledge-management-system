# 安全指南

## 概述

打印机维护涉及电气、热、机械和化学危害。遵循这些安全指南可保护人员和设备。所有维护人员必须在执行本手册中的任何程序之前阅读并理解本部分。

---

## 通用安全原则

1. **如有疑问，请停止操作。** 如果一项程序感觉不安全或超出您的培训范围，请勿继续操作 — 升级至合格技术人员。
2. **一人一任务。** 不要在另一个人也在同一台打印机上工作时进行维护。
3. **沟通。** 如果您正在处理打印机，请放置一个“停机维护中”的标志，以便用户不要尝试使用它。
4. **不要走捷径。** 永远不要绕过安全互锁或用胶带固定门开关来打开盖子操作打印机。
5. **急救。** 知道最近急救包、洗眼站和灭火器的位置。

---

## 电气安全

### 在任何内部维护之前

- [ ] 使用电源按钮关闭打印机电源（运行时不要拔掉打印机电源插头）
- [ ] 将电源线从插座拔下
- [ ] 如果打印机有独立的电源开关，将其设置为“关”
- [ ] 通过尝试打开打印机来验证打印机已断开连接

### 电气危害

| 危害 | 风险 | 预防措施 |
|--------|------|------------|
| 高压电源 | 电击，烧伤 | 永远不要打开电源供应外壳；仅由合格人员服务 |
| 激光扫描单元 | 激光辐射可能损伤眼睛 | 不要打开激光扫描盖；当关闭时，互锁防止暴露 |
| 潮湿的手/环境 | 增加触电风险 | 确保手是干燥的；不要在电气组件附近使用水 |
| 损坏的电源线 | 触电，火灾 | 定期检查电缆；如有裂纹、磨损或挤压，则更换 |
| 过载插座 | 火灾 | 使用专用插座；不要将电源线串联在一起 |

!!! danger "激光安全"
    激光打印机使用激光束在鼓上写入图像。永远不要尝试破坏门互锁开关或看向激光扫描组件。激光是不可见的，可能造成永久性眼损伤。

## 热安全

### 熔合单元

熔合器是激光打印机中最热的部件，工作温度为 **180–220 °C (356–428 °F)**。

- 始终在关闭电源后等待 30 分钟再触摸熔合器区域。
- 即使经过 30 分钟，熔合器可能仍然很热 — 小心触摸。
- 使用指定的把手或杠杆；永远不要直接抓住熔合器滚筒。
- 如果闻到烧焦味或看到烟雾，立即关闭电源，拔掉插头，并在必要时疏散该区域。

### 其他热部件

- **转印滚筒** — 在长时间打印过程中可能变热
- **双面打印路径** — 通过的纸张可能触摸到很热
- **喷墨打印头** — 一些喷墨打印机将打印头加热到 40–60 °C

### 烧伤急救

1. 立即移除热源。
2. 在冷水（不是冷水）下冷却烧伤 10–20 分钟。
3. 不要在严重烧伤上涂抹冰、黄油或药膏。
4. 用干净的无粘性敷料包扎。
5. 对于大于硬币的烧伤、水泡烧伤或面部/手部的烧伤，寻求医疗帮助。

## 机械安全

### 捏合点和运动部件

打印机包含齿轮、滚筒、皮带和电机，可能会夹住手指或拉入珠宝、头发或衣物。

- **永远不要** 在打印机开启并运行时伸进打印机。
- 在维护前取下戒指、手表、手镯和悬垂的珠宝。
- 扎起长发。
- 不要在运动部件附近穿宽松的袖子或围巾。
- 使用提供的杠杆和把手 — 不要强行移动组件。

### 重物搬运

- 桌面打印机（重量低于 20 kg）：用腿抬，不要用背。
- 立式/多功能打印机（重量超过 20 kg）：**需要两人**或搬运车。
- 永远不要用手推车、扫描器盖或纸盒来抬打印机 — 这些不是结构部件。
- 确保目的地表面平坦、稳定，并经过重量评级。

## 化学安全

### 碳粉

碳粉是一种细小的塑料粉末（聚酯或苯乙烯-丙烯酸酯）和颜料。虽然不是高度有毒，但需要小心处理。

| 危害 | 预防措施 |
|--------|------------|
| 细小粉末吸入 | 在通风良好的区域工作；避免产生粉尘云 |
| 皮肤刺激 | 穿戴丁腈手套；处理后洗手 |
| 眼睛刺激 | 如果处理大量泄漏，请戴安全眼镜 |
| 衣物染色 | 穿戴实验服或围裙；碳粉污渍难以去除 |
| 空气中飞扬时的火灾风险 | 将碳粉远离明火和高热源 |

### 碳粉泄漏应对

1. **不要使用标准吸尘器** — 它可以使粉末气溶胶化并损坏吸尘器电机。
2. 如果可用，使用碳粉专用HEPA吸尘器。
3. 否则，使用干燥的无绒布轻轻抬起粉末（不要摩擦 — 这会将其磨碎）。
4. 对于残留的灰尘，使用略微湿润的布（仅用水）。
5. 让表面完全干燥。
6. 将受污染的材料作为电子垃圾处理，而不是普通垃圾。

### 异丙醇

- 在通风良好的区域使用 — 气体易燃。
- 远离明火和热源。
- 不要在熔合器或电气接触附近喷洒。
- 存放在密封容器中，远离热源和直射阳光。
- 如果溅到皮肤上，用肥皂和水冲洗。
- 如果眼睛接触，用水冲洗 15 分钟并寻求医疗帮助。

### 清洁剂

- 只使用本手册或制造商指南中指定的清洁剂。
- 永远不要混合清洁产品（例如，漂白剂+氨 = 有毒氯胺气体）。
- 将所有清洁化学品存放在原始、标有标签的容器中。
- 将易燃液体（异丙醇）存放在耐火柜中。

## 个人防护装备 (PPE)

### 所有维护所需

- [ ] **丁腈手套** — 用于处理碳粉、脏组件和化学品
- [ ] **安全眼镜** — 当使用压缩空气或处理碳粉泄漏时
- [ ] **封闭式鞋子** — 在所有打印机房间

### 特定情况下的PPE

| 任务 | 额外PPE |
|------|---------------|
| 熔合器区域维护 | 防热手套（冷却后），长袖 |
| 大量碳粉泄漏 | N95防尘口罩，安全眼镜，手套 |
| 压缩空气清洁 | 安全眼镜（灰尘/碎片） |
| 搬运重型打印机 | 钢头鞋，背部支撑带 |
| 在肩部以上工作 | 梯子（不是椅子或盒子） |

## 环境安全

### 通风

- 打印机房间应具备足够的通风或HVAC。
- 激光打印机在运行时排放低水平的臭氧和超细颗粒。
- 对于每月打印量高的打印机（10,000+页），考虑专用通风系统或带有HEPA和活性炭的空气净化器。
- 不要将打印机放在小、未通风的壁橱中。

### 火灾安全

- 将打印机至少保持 1 米远离易燃材料。
- 确保该区域有可及的C类（电气）灭火器。
- 永远不要在电气火灾上使用水 — 使用CO₂或干粉灭火器。
- 如果打印机着火：**如果安全，则拔掉插头**，疏散，并拨打紧急服务。

### 废弃物处理

| 废弃物 | 处理方法 |
|-------|-----------------|
| 使用过的碳粉盒 | 制造商回收计划（免费邮寄回） |
| 废弃碳粉 | 封装在塑料袋中；电子垃圾处理设施 |
| 异丙醇容器 | 有害废物/化学品处理 |
| 含碳粉的清洁布 | 电子垃圾或受污染的废物 |
| 旧打印机/部件 | 电子垃圾回收（不要填埋 — 含有重金属） |
| 纸张 | 标准纸张回收 |

## 紧急程序

### 电击

1. **如果受害者仍然接触电源，不要触摸受害者**。
2. 在断路器处切断电源或拔掉设备插头。
3. 立即拨打紧急服务。
4. 如果受害者无反应且没有呼吸，如果受过培训，则开始心肺复苏。
5. 不要移动受害者，除非他们处于直接危险。

### 火灾

1. 激活火灾警报。
2. 如果安全，则拔掉打印机插头。
3. 使用C类灭火器（CO₂或干粉）——**永远不要用水**。
4. 如果火势蔓延或无法控制，疏散并关闭门。
5. 拨打紧急服务。

### 碳粉进入眼睛

1. 不要揉眼睛。
2. 立即用干净、温水冲洗至少 15 分钟，同时睁开眼睑。
3. 寻求医疗帮助。

### 运动部件造成的伤害

1. 立即关闭电源并拔掉插头。
2. 不要试图用力拉出卡住的肢体 — 分解或寻求帮助。
3. 对割伤或擦伤进行急救。
4. 对于挤压伤、深割伤或疑似骨折，寻求医疗帮助。

## 打印机安全检查清单（每台打印机后）

在每台打印机附近张贴此清单：

- [ ] 关闭电源并拔掉插头后再打开盖子
- [ ] 等待 30 分钟让熔合器冷却
- [ ] 在需要时佩戴手套和安全眼镜
- [ ] 不要在电气组件附近使用水或液体清洁剂
- [ ] 不要使用标准吸尘器清理碳粉泄漏
- [ ] 不要破坏门互锁
- [ ] 保持区域无杂物和易燃物品
- [ ] 报告所有事故和险些发生的事故
