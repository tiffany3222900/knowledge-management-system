# 故障排除指南

## 概述

本节提供了最常见的打印机问题的症状到解决方案的参考。问题按类别组织。始终从最简单的解决方案开始，例如电源循环，然后逐步进行更复杂的修复。

---

## 快速修复：电源循环

在进行任何高级故障排除之前，请执行电源循环。这可以解决大约40%的瞬时错误。

1. 按下电源按钮关闭打印机。
2. **拔下**电源线从插座（不仅是打印机）。
3. 等待**60秒**——这允许电容器放电和内存清除。
4. 在等待时，检查所有盖子是否关闭且没有纸张卡住。
5. 将电源线重新插回。
6. 打开电源并等待打印机达到“就绪”状态。
7. 打印测试页。

!!! note "网络打印机"
    如果打印机已连接到网络，如果连接问题持续存在，请重新启动网络交换机或路由器端口。

## 打印质量问题

### 淡化或浅色打印

| 可能原因 | 解决方案 |
|----------------|----------|
| 色粉盒低或空 | 更换色粉盒 |
| 色粉分布不均匀 | 取出色粉盒，轻轻摇动5次，然后重新安装 |
| 经济模式/省墨模式开启 | 在打印机设置中禁用省墨模式 |
| 鼓单元接近寿命结束 | 更换鼓单元 |
| 纸张潮湿或太厚 | 使用符合规格的新鲜干燥纸张 |
| 传输滚筒脏或磨损 | 清洁传输滚筒；如有必要，更换 |
| 激光扫描窗口脏 | 清洁扫描窗口（某些型号可通过前盖访问） |

### 垂直条纹或线条

| 图案 | 原因 | 解决方案 |
|---------|-------|----------|
| 黑色垂直线条 | 损坏的鼓或色粉盒 | 更换色粉；如果持续存在，更换鼓 |
| 白色垂直线条 | 色粉堵塞或开发滚筒脏 | 更换色粉盒 |
| 定期间隔重复的斑点 | 鼓损坏或熔合滚筒损坏 | 测量间隔；更换鼓或熔合滚筒 |
| 扫描/复制上的条纹 | 扫描玻璃或ADF玻璃条脏 | 清洁扫描玻璃（见[清洁](cleaning.md)） |
| 所有打印上的相同位置上的条纹 | 冠线脏或主充电滚筒脏 | 按制造商说明清洁；更换鼓 |

### 污点或色粉掉色

| 原因 | 解决方案 |
|-------|----------|
| 熔合温度太低 | 检查纸张类型设置（厚纸需要更高的熔合温度） |
| 熔合单元磨损或故障 | 更换熔合单元（维护套件） |
| 纸张太厚或纹理不正确 | 使用符合打印机重量规格的纸张 |
| 色粉非OEM/不兼容 | 使用真正的OEM色粉 |
| 打印速度对于媒体来说太高 | 在驱动程序设置中降低打印速度 |

### 幻影/重复图像

图像在页面下方出现微弱的副本。

- **原因**：磨损的鼓或熔合滚筒；图像未完全转移或熔合。
- **修复**：首先更换鼓单元。如果幻影持续存在，更换熔合滚筒。

### 颜色问题（彩色打印机）

| 症状 | 原因 | 解决方案 |
|---------|-------|----------|
| 一色缺失 | 空盒或喷嘴堵塞 | 更换盒；运行头部清洁（喷墨） |
| 颜色错误/偏移 | 颜色注册不齐 | 从菜单运行自动颜色校准 |
| 颜色带状 | 污染的LED打印头或故障盒 | 清洁；更换受影响的盒 |
| 所有颜色都淡化 | 转移带接近寿命结束 | 更换转移带（维护套件） |
| 背景雾蒙蒙 | 误设色粉密度设置 | 重置为出厂默认值；更换鼓 |

## 纸张进纸问题

### 打印机显示“无纸”但已加载纸张

1. 取出纸盒并检查拾取滚筒。
2. 用异丙醇清洁滚筒。
3. 检查纸张大小传感器标志是否卡住。
4. 核实纸张是否低于最大填充线且高于最小线。
5. 确保纸盒完全插入（直到卡扣响起）。
6. 如果问题持续存在，拾取滚筒可能需要更换。

### 一次性进纸多张

1. 取出纸张并彻底扇动以减少静电。
2. 检查纸张是否潮湿（更换新鲜库存）。
3. 用异丙醇清洁分离垫。
4. 如果分离垫磨损光滑，则更换它。
5. 不要在同一个纸盒中混合纸张类型或重量。

### 纸张偏斜/打印歪斜

1. 检查纸盒中的纸张导轨是否紧贴堆叠。
2. 确保纸张加载平稳（不要成角度）。
3. 清洁进纸滚筒——不均匀的滚筒磨损会导致偏斜。
4. 检查纸张路径中是否有撕裂的纸张碎片导致不对称的拖动。
5. 核实纸盒是否变形或损坏。

## 错误代码

### 常见错误代码（通用）

| 代码 | 含义 | 操作 |
|------|---------|--------|
| **E1** / **13.xx** | 纸张卡住 | 按照以下[纸张处理](paper-handling.md)清除卡纸 |
| **E2** / **10.xx** | 纸张大小不匹配 | 核实纸盒纸张大小与驱动程序设置匹配 |
| **E3** / **50.xx** | 熔合错误 | 电源循环；如果持续存在，更换熔合单元 |
| **E4** / **51.xx** | 激光扫描错误 | 电源循环；如果持续存在，需要维修 |
| **E5** / **52.xx** | 电机错误 | 检查是否有障碍物；需要维修 |
| **E6** / **53.xx** | 内存错误 | 电源循环；如果可升级，重新安装内存 |
| **E7** / **54.xx** | 颜色注册错误 | 运行自动校准；如果持续存在，需要维修 |
| **79.xx** | 固件错误 | 电源循环；更新固件；删除故障打印作业 |
| **50.4** | 熔合电源供应错误 | 检查电源插座；尝试不同的电路 |

!!! note "型号特定代码"
    错误代码因制造商而异（HP、Canon、Brother、Epson、Xerox等）。始终参考打印机的服务手册以获取确切的代码定义。上面的代码是通用模式。

### 79服务错误（HP通用）

这是一个固件崩溃，通常由损坏的打印作业引起。

1. 关闭打印机并拔掉电源60秒。
2. 关闭时，从计算机的打印队列中清除所有打印作业。
3. 插入并打开电源。
4. 如果错误在没有发送作业的情况下返回，更新固件。
5. 如果错误仅在打印特定文件时出现，则文件已损坏——重新保存或重新导出它。

## 网络和连接问题

### 打印机离线/未在网络中找到

1. 从打印机的控制面板打印配置页面以验证其IP地址。
2. 从同一网络上的计算机，ping打印机的IP地址。
    - 如果ping失败：检查网络电缆、交换机端口和打印机网络设置。
    - 如果ping成功：问题是计算机上的打印机驱动器/端口。
3. 核实打印机具有静态IP地址（DHCP地址可能会更改并中断连接）。
4. 在Windows上重新启动打印池服务：
    ```
    net stop spooler
    net start spooler
    ```
5. 在受影响的计算机上删除并重新添加打印机。
6. 将打印机驱动程序更新到最新版本。

### 网络打印速度慢

- 检查网络电缆（如果可能，用Cat6替换Cat5e）
- 降低打印分辨率或使用“快速”打印模式进行草稿
- 在打印机驱动程序中禁用“保留打印文档”
- 更新固件和网络卡驱动程序
- 对于大型文档，使用直接USB连接作为解决方案

### 扫描到电子邮件失败

1. 核实打印机已配置有效的DNS服务器。
2. 检查SMTP服务器设置（地址、端口、身份验证、加密）。
3. 使用已知工作的电子邮件地址进行测试。
4. 如果使用Office 365/Gmail，确保已配置“不安全的应用程序”访问或应用程序密码。
5. 检查防火墙设置——打印机必须能够到达SMTP端口。

## 硬件和机械问题

### 不寻常的噪音

| 噪音 | 可能原因 | 操作 |
|-------|-------------|--------|
| 磨擦/点击 | 齿轮传动问题，齿轮中的撕裂纸张 | 检查纸张碎片；如果持续存在，则维修 |
| 呱呱叫 | 干燥或磨损的滚筒 | 按服务手册清洁/润滑；如有必要，更换滚筒 |
| 高音调嗡嗡声 | 熔合轴承或电机故障 | 更换熔合单元或电机 |
| 响亮的重击 | 不平衡的鼓或色粉盒 | 重新安装或更换色粉盒 |
| 嗡嗡声/嗡嗡声 | 电源供应或变压器 | 如果微弱，则正常；如果响亮或新，则维修 |

### 打印机无法开机

1. 核实电源线两端是否牢固连接。
2. 尝试不同的电源插座（用另一个设备测试插座）。
3. 尝试不同的电源线。
4. 检查电源开关是否处于“开”位置。
5. 如果打印机有电源模块，它可能需要更换。
6. 如果最近出现过电源浪涌，保险丝或电源可能已损坏——需要维修。

### 控制面板显示屏问题

- **空白显示屏**：检查电源；调整显示屏对比度/亮度；显示屏模块可能已损坏。
- **显示乱码**：固件损坏——更新固件；如果无法更新，则维修。
- **触摸屏无响应**：清洁屏幕；如有可用的触摸校准，则重新校准；触摸面板可能需要更换。
- **按钮无响应**：粘稠或磨损的按钮——清洁按钮周围；控制面板可能需要更换。

## 软件和驱动程序问题

### 打印作业卡在队列中

1. 打开计算机上的打印队列。
2. 取消所有文档。
3. 在Windows上重新启动打印池服务或Linux/macOS上的cups服务。
4. 电源循环打印机。
5. 重新发送打印作业。

### 纸张大小或方向错误

- 检查应用程序打印对话框中的纸张大小设置。
- 核实打印机驱动程序的默认纸张大小与加载的纸张匹配。
- 确保打印机的控制面板报告每个纸盒的正确纸张大小。
- 对于混合大小的文档，使用“按纸盒选择”或自动选择。

### 打印机打印乱码

- 安装了错误的打印机驱动程序——下载并安装适用于型号的正确驱动程序。
- 打印作业已损坏——取消并重新发送。
- 接口电缆故障——更换USB或网络电缆。
- 固件过时——更新到最新版本。

## 当升级

当以下情况发生时，请联系IT支持或授权服务提供商：

- 电源循环和基本故障排除后错误代码持续存在
- 色粉、鼓和清洁后打印质量没有改善
- 清洁滚筒后（2+次/天）出现重复卡纸
- 任何硬件错误（熔合单元、激光扫描仪、电机、电源）
- 打印机或附件的物理损坏
- 打印机在保修期内——不要打开密封组件（无效保修）
- 固件更新失败或设备损坏
- 无法通过基本检查解决的网络问题

## 故障排除决策流程

```
开始
  │
  ├─ 电源循环解决它？ ──是──→ 完成（记录瞬时错误）
  │
  └─ 否
      │
      ├─ 显示屏上有错误代码？ ──是──→ 查找代码 → 执行修复
      │
      └─ 无代码
          │
          ├─ 纸张卡住？ ──是──→ 清除卡纸 → 测试
          │
          ├─ 打印质量问题？ ──是──→ 检查色粉 → 鼓 → 清洁 → 熔合
          │
          ├─ 连接问题？ ──是──→ 检查IP → Ping → 驱动程序 → 打印池
          │
          └─ 其他 ──→ 咨询服务手册 → 升级
```
