# 故障排除指南

## 概述

本节为最常见的打印机问题提供症状到解决方案的参考。问题按类别组织。始终从最简单的解决方案（重启电源）开始，逐步进行更复杂的修复。

---

## 快速修复：重启电源

在进行任何高级故障排除之前，执行重启电源。这可以解决约40%的瞬时错误。

1. 按电源按钮关闭打印机。
2. 从墙壁插座**拔下**电源线（不仅仅是从打印机上）。
3. 等待**60秒** — 这允许电容器放电和内存清除。
4. 等待期间，检查所有盖子是否关闭且无卡纸。
5. 重新插好电源线。
6. 开机并等待打印机达到"就绪"状态。
7. 打印测试页。

!!! note "网络打印机"
    如果打印机是网络连接的，如连接问题持续，还应重启网络交换机或路由器端口。

## 打印质量问题

### 褪色或浅色打印

| 可能原因 | 解决方案 |
|----------|----------|
| 碳粉盒不足或已空 | 更换碳粉盒 |
| 碳粉分布不均 | 取出碳粉盒，轻轻左右摇晃5次，重新安装 |
| 省墨模式已开启 | 在打印机设置中禁用省墨模式 |
| 硒鼓单元接近寿命终点 | 更换硒鼓单元 |
| 纸张潮湿或太厚 | 更换为规格内的新鲜干燥纸张 |
| 转印辊脏或磨损 | 清洁转印辊；必要时更换 |
| 激光扫描窗口脏 | 清洁扫描窗口（某些型号可通过前盖接触） |

### 垂直条纹或线条

| 图案 | 原因 | 解决方案 |
|------|------|----------|
| 黑色垂直线 | 硒鼓或碳粉盒损坏 | 先更换碳粉；如持续则更换硒鼓 |
| 白色垂直线 | 碳粉堵塞或显影辊脏 | 更换碳粉盒 |
| 固定间隔重复斑点 | 硒鼓损坏或定影辊损坏 | 测量间隔；更换硒鼓或定影器 |
| 仅扫描/复印有条纹 | 扫描玻璃或自动输稿器玻璃条脏 | 清洁扫描玻璃（参见 [清洁](cleaning.md)） |
| 所有打印件同一位置有条纹 | 电晕丝或主充电辊脏 | 按制造商说明清洁；更换硒鼓 |

### 污渍或碳粉脱落

| 原因 | 解决方案 |
|------|----------|
| 定影器温度过低 | 检查纸张类型设置（厚纸需要更高定影温度） |
| 定影器单元磨损或故障 | 更换定影器（维护套件） |
| 纸张太厚或纹理错误 | 使用打印机克重规格内的纸张 |
| 非原装 / 不兼容碳粉 | 使用原装正品碳粉 |
| 打印速度对介质来说过高 | 在驱动设置中降低厚介质的打印速度 |

### 重影 / 重复图像

页面下方出现图像的淡色副本。

- **原因**：硒鼓或定影辊磨损；图像未完全转印或熔化。
- **修复**：先更换硒鼓单元。如重影持续，更换定影器。

### 颜色问题（彩色打印机）

| 症状 | 原因 | 解决方案 |
|------|------|----------|
| 缺少一种颜色 | 墨盒空或喷嘴堵塞 | 更换墨盒；运行喷头清洁（喷墨） |
| 颜色错误 / 偏移 | 颜色套准未对齐 | 从菜单运行自动颜色校准 |
| 颜色条带 | LED打印头脏或墨盒故障 | 清洁；更换受影响的墨盒 |
| 所有颜色褪色 | 转印带接近寿命终点 | 更换转印带（维护套件） |
| 背景灰雾 | 碳粉浓度设置错误 | 恢复出厂默认；更换硒鼓 |

## 进纸问题

### 打印机显示"无纸"但已装纸

1. 取出纸盒并检查搓纸辊。
2. 用异丙醇清洁辊子。
3. 检查纸张尺寸传感器拨杆是否卡住。
4. 验证纸张在最大填充线以下且在最低线以上。
5. 确保纸盒完全插入（用力推直到咔嗒）。
6. 如问题持续，搓纸辊可能需要更换。

### 一次进多张纸

1. 取出纸张并充分扇形展开以减少静电。
2. 检查纸张是否潮湿（更换为新鲜纸张）。
3. 用异丙醇清洁分离垫。
4. 如果分离垫磨损光滑，更换它。
5. 不要在同一纸盒中混合纸张类型或克重。

### 纸张歪斜 / 打印歪斜

1. 检查纸盒中的纸张导板是否紧贴纸叠。
2. 确保纸张方正装入（不是斜着）。
3. 清洁进纸辊 — 辊子磨损不均会导致歪斜。
4. 检查走纸通道中是否有碎纸片导致不对称阻力。
5. 验证纸盒是否变形或损坏。

## 错误代码

### 常见错误代码（通用）

| 代码 | 含义 | 操作 |
|------|------|------|
| **E1** / **13.xx** | 卡纸 | 按 [纸张处理](paper-handling.md) 清除卡纸 |
| **E2** / **10.xx** | 纸张尺寸不匹配 | 验证纸盒纸张尺寸与驱动设置匹配 |
| **E3** / **50.xx** | 定影器错误 | 重启电源；如持续则更换定影器 |
| **E4** / **51.xx** | 激光扫描器错误 | 重启电源；如持续则需要维修 |
| **E5** / **52.xx** | 电机错误 | 检查是否有障碍物；需要维修 |
| **E6** / **53.xx** | 内存错误 | 重启电源；如可升级则重新插拔内存 |
| **E7** / **54.xx** | 颜色套准错误 | 运行自动校准；如持续则维修 |
| **79.xx** | 固件错误 | 重启电源；更新固件；删除有问题的打印任务 |
| **50.4** | 定影器电源错误 | 检查电源插座；尝试其他电路 |

!!! note "型号特定代码"
    错误代码因制造商而异（HP、Canon、Brother、Epson、Xerox等）。请始终参阅打印机服务手册获取确切代码定义。以上代码为通用模式。

### 79服务错误（HP常见）

这是固件崩溃，通常由损坏的打印任务引起。

1. 关闭打印机并拔下电源60秒。
2. 关机期间，从计算机打印队列中清除所有打印任务。
3. 插电并开机。
4. 如果未发送任务即出现错误，更新固件。
5. 如果仅在打印特定文件时出现错误，说明文件已损坏 — 重新保存或重新导出。

## 网络和连接问题

### 打印机离线 / 网络上找不到

1. 从打印机控制面板打印配置页以验证其IP地址。
2. 从同一网络上的计算机ping打印机IP地址。
    - 如果ping失败：检查网线、交换机端口和打印机网络设置。
    - 如果ping成功：问题出在计算机上的打印机驱动/端口。
3. 验证打印机有静态IP地址（DHCP地址可能变化并断开连接）。
4. 在Windows上重启打印后台处理程序服务：
    ```
    net stop spooler
    net start spooler
    ```
5. 在受影响的计算机上删除并重新添加打印机。
6. 将打印机驱动更新到最新版本。

### 网络打印缓慢

- 检查网线（如可能将Cat5e更换为Cat6）
- 降低打印分辨率或对草稿使用"快速"打印模式
- 在打印机驱动中禁用"保留打印文档"
- 更新固件和网卡驱动
- 对于大文档，使用直接USB连接作为临时解决方案

### 扫描到邮件失败

1. 验证打印机已配置有效的DNS服务器。
2. 检查SMTP服务器设置（地址、端口、认证、加密）。
3. 用已知可用的电子邮件地址测试。
4. 如果使用Office 365 / Gmail，确保已配置"低安全性应用"访问或应用密码。
5. 检查防火墙设置 — 打印机必须能访问SMTP端口。

## 硬件和机械问题

### 异常噪音

| 噪音 | 可能原因 | 操作 |
|------|----------|------|
| 研磨 / 咔嗒声 | 齿轮系问题，齿轮中有碎纸 | 检查纸屑；如持续则维修 |
| 尖叫声 | 辊子干燥或磨损 | 按服务手册清洁/润滑；更换辊子 |
| 高频啸叫 | 定影器轴承或电机故障 | 更换定影器或电机 |
| 大声砰砰声 | 硒鼓或碳粉盒不平衡 | 重新安装或更换墨盒 |
| 嗡嗡 / 哼哼声 | 电源或变压器 | 如微弱则正常；如大声或新出现则维修 |

### 打印机不开机

1. 验证电源线两端连接牢固。
2. 尝试其他电源插座（用其他设备测试插座）。
3. 尝试其他电源线。
4. 检查电源开关处于"开"位置。
5. 如果打印机有电源模块，可能需要更换。
6. 如果最近有电涌，保险丝或电源可能损坏 — 需要维修。

### 控制面板显示问题

- **空白显示**：检查电源；调整显示对比度/亮度；显示模块可能故障。
- **显示乱码**：固件损坏 — 更新固件；如无法更新则需要维修。
- **触摸屏无响应**：清洁屏幕；如可用则重新校准触摸；触摸面板可能需要更换。
- **按钮无响应**：按钮粘滞或磨损 — 清洁按钮周围；控制面板可能需要更换。

## 软件和驱动问题

### 打印任务卡在队列中

1. 打开计算机上的打印队列。
2. 取消所有文档。
3. 重启打印后台处理程序服务（Windows）或cups服务（Linux/macOS）。
4. 重启打印机。
5. 重新发送打印任务。

### 纸张尺寸或方向错误

- 检查应用程序打印对话框中的纸张尺寸设置。
- 验证打印机驱动的默认纸张尺寸与装入的纸张匹配。
- 确保打印机控制面板为每个纸盒报告正确的纸张尺寸。
- 对于混合尺寸文档，使用"按纸张来源选择"或自动选择。

### 打印机打印乱码

- 安装了错误的打印机驱动 — 下载并安装适用于该型号的正确驱动。
- 打印任务损坏 — 取消并重新发送。
- 接口电缆故障 — 更换USB或网线。
- 固件过时 — 更新到最新版本。

## 何时升级

在以下情况下联系IT支持或授权服务提供商：

- [ ] 重启电源和基础故障排除后错误代码仍持续
- [ ] 更换碳粉、硒鼓和清洁后打印质量仍未改善
- [ ] 清洁辊子后仍反复卡纸（每天2次以上）
- [ ] 任何硬件错误（定影器、激光扫描器、电机、电源）
- [ ] 打印机或配件的物理损坏
- [ ] 打印机在保修期内 — 不要打开密封组件（会使保修失效）
- [ ] 固件更新失败或设备变砖
- [ ] 基础检查无法解决的网络问题

## 故障排除决策流程

```
开始
  │
  ├─ 重启电源能解决？ ──是──→ 完成（记录瞬时错误）
  │
  └─ 否
      │
      ├─ 显示屏有错误代码？ ──是──→ 查找代码 → 按修复方法操作
      │
      └─ 无代码
          │
          ├─ 卡纸？ ──是──→ 清除卡纸 → 测试
          │
          ├─ 打印质量问题？ ──是──→ 检查碳粉 → 硒鼓 → 清洁 → 定影器
          │
          ├─ 连接问题？ ──是──→ 检查IP → Ping → 驱动 → 后台处理程序
          │
          └─ 其他 ──→ 查阅服务手册 → 升级处理
```
