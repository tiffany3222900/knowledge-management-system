# 纸张处理与卡纸清除

## 概述

卡纸是最常见的打印机问题。大多数卡纸由不正确的装纸、辊子磨损或纸张损坏引起。本节涵盖正确的装纸流程和所有常见卡纸位置的分步清除方法。

---

## 正确装纸

### 标准流程

1. **取出纸盒** — 直接拉出打印机。
2. **将纸叠扇形展开** — 握住纸叠两端并弯曲，然后将页面扇形展开。这可以分离纸张并减少静电。
3. **在平面上轻敲纸叠**以使边缘整齐对齐。
4. **装入纸张** — **打印面朝下**放入纸盒（查看纸盒标签确认方向）。
5. **调整纸张导板** — 滑动侧边和末端导板直到紧贴纸叠。
    - 太松 → 纸张歪斜 → 卡纸
    - 太紧 → 纸张弯曲 → 卡纸
6. **不要过满** — 保持纸张低于纸盒上标记的最大填充线。
7. **重新插入纸盒**直到咔嗒到位。
8. 如提示，在控制面板上**确认纸张尺寸**。

!!! tip "黄金法则"
    如果打印机有纸张尺寸传感器，请始终验证显示的尺寸与实际纸张匹配。不匹配会导致90%的"幽灵"卡纸和进纸错误。

### 装入信封、标签和特殊介质

| 介质类型 | 纸盒 | 方向 | 注意事项 |
|----------|------|------|----------|
| 信封 | 手动进纸（多功能纸盒） | 面朝下，翻盖朝上，左边先入 | 不要使用带窗口或金属扣的信封 |
| 标签 | 手动进纸或第1纸盒 | 面朝下，标签面朝下 | 仅使用激光适用标签；不要送入已部分使用的标签纸 |
| 透明胶片 | 手动进纸 | 粗糙面朝下（查看包装） | 仅使用激光适用透明胶片 |
| 卡片纸 / 厚纸 | 手动进纸 | 面朝下 | 查看最大克重规格（通常163-216 g/m²） |
| 信头纸 / 预印纸 | 纸盒或多功能纸盒 | 面朝下，顶边朝向打印机 | 先测试一张确认方向 |

## 了解卡纸位置

卡纸可能发生在多个区域。打印机控制面板通常会显示卡纸位置示意图。

```
                    ┌──────────────────────┐
                    │   自动输稿器 / 扫描卡纸 │  ← 顶部区域
                    └──────────┬───────────┘
                               │
┌──────────────────────────────┼──────────────────────────────┐
│  纸盒                        │   出纸区域                    │
│  （第1纸盒 / 第2纸盒）        │   （出纸辊）                  │
│  ← 搓纸卡纸                  │   ← 出纸卡纸 / 缠绕           │
└──────────────┬───────────────┴──────────────┬───────────────┘
               │                              │
        ┌──────▼──────┐               ┌──────▼──────┐
        │  走纸通道   │               │   定影器卡纸 │
        │  （内部）   │               │  （后部）    │
        └─────────────┘               └─────────────┘
```

## 通用卡纸清除流程

!!! danger "安全第一"
    1. 打开盖子前关闭打印机。
    2. 定影器区域**极热** — 如接触后部请等待30分钟。
    3. 沿正常走纸方向**缓慢平稳**地拉纸。切勿猛拉。
    4. 如果纸张撕裂，清除**每一片**碎屑 — 即使很小的碎片也会导致再次卡纸。

### 分步操作

1. **停止打印机** — 按停止/取消按钮，然后关机。
2. **查看显示屏** — 记下指示的卡纸位置。
3. **打开对应位置的盖子**（参见以下各节）。
4. **轻轻取出纸张**，尽可能用双手。
5. **检查是否有撕裂碎片** — 用手电筒检查辊子和导板。
6. **牢固关闭所有盖子**。
7. **开机** — 打印机可能运行校准或自动重新打印被卡住的页面。
8. **打印测试页**确认正常运行。

## 卡纸位置：纸盒 / 搓纸区域

### 症状
- 即使已装纸仍显示"无纸"错误
- 纸张完全不进纸
- 纸盒区域发出研磨声
- 一次进多张纸

### 解决方法

1. 取出纸盒。
2. 检查纸盒腔顶部是否有部分可见的进纸错误纸张。
3. 如可见，轻轻向下直接拉出纸张。
4. 如不可见，检查搓纸辊区域 — 纸张可能缠绕在辊子上。
5. 取出纸张，然后检查搓纸辊：
    - 如有灰尘用异丙醇清洁（参见 [清洁](cleaning.md)）。
    - 如果辊子表面光滑/磨光，则需要更换。
6. 将纸张扇形展开并重新装入，确保导板正确调整。
7. 重新插入纸盒并测试。

### 预防搓纸卡纸

- 不要过满纸盒（保持在填充线以下）
- 装纸前将纸张扇形展开
- 保持纸张干燥（湿度导致纸张粘连）
- 每月清洁进纸辊
- 不要在同一纸盒中混合纸张尺寸

## 卡纸位置：内部走纸通道

### 症状
- "内部卡纸"或"打印通道卡纸"消息
- 纸张在打印机中途停止

### 解决方法

1. 打开前盖。
2. 取出碳粉 / 硒鼓单元组件。
3. 向走纸通道内查看卡住的纸张。
4. 沿正常走纸方向（朝前或朝出纸口，视型号而定）**直接拉出**纸张。
5. 如果纸张缠绕在辊子上，手动旋转辊子（沿正常方向）将纸张送出。
6. 如有必要，用镊子取出小撕裂碎片。
7. 重新安装碳粉 / 硒鼓单元。
8. 关闭盖子并测试。

## 卡纸位置：定影器区域（后部）

!!! danger "高温 — 需要30分钟冷却"
    定影器工作温度约为180-220°C。务必关机、拔下电源并等待至少30分钟后再打开后部定影器盖。

### 症状
- "后部卡纸"或"定影器卡纸"消息
- 纸张部分退出后停止
- 出纸处纸张褶皱或缠绕

### 解决方法

1. 关机、拔下电源并等待30分钟。
2. 打开后盖（或定影器检修门）。
3. 放下定影器压力释放杆（如有）— 这会释放辊子压力。
4. 朝后部直接拉出纸张。
    - 如果纸张缠绕在上定影辊上，手动旋转辊子齿轮将其送出。
5. 检查定影器内部是否有撕裂碎片。
6. 将压力杆恢复到原始位置。
7. 关闭后盖。
8. 插电、开机并打印2-3张空白页以清除残留碳粉。

!!! warning "不要使用尖锐物体"
    切勿用剪刀、刀或螺丝刀从定影器中取纸。刮伤定影辊会导致永久性打印缺陷。

## 卡纸位置：出纸区域

### 症状
- 纸张部分退出后停止
- "出纸口卡纸"消息
- 纸张在出口处卷曲或折叠

### 解决方法

1. 打开前部或顶部出纸盖。
2. 轻轻朝出纸托盘方向直接拉出纸张。
3. 如果纸张撕裂，打开后盖并从定影器出口取出剩余碎片。
4. 检查出纸辊是否有磨损或碳粉堆积。
5. 关闭盖子并测试。

---

## 卡纸位置：自动输稿器 / 扫描仪

### 症状
- 自动输稿器中"文档卡纸"
- 原始文档不进纸或中途停止

### 解决方法

1. 打开自动输稿器盖。
2. 轻轻直接拉出原始文档。
3. 如撕裂，清除进纸通道中的所有碎片。
4. 用异丙醇清洁自动输稿器进纸辊和分离垫。
5. 关闭自动输稿器盖。
6. 用单张纸测试。

### 预防自动输稿器卡纸

- 装纸前移除订书钉、回形针和便利贴
- 不要装入超过自动输稿器容量的纸张（通常20-50页）
- 装纸前将原稿扇形展开
- 不要使用褶皱、撕裂或严重卷曲的原稿
- 将自动输稿器纸张导板调整到文档宽度

## 反复卡纸：根本原因分析

如果同一台打印机反复卡纸（每天2次以上），调查以下原因：

| 症状模式 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 每次都在搓纸处卡纸 | 搓纸辊磨损/磨光 | 清洁或更换辊子 |
| 在通道同一点卡纸 | 通道中残留碎纸片 | 全面检查，清除所有碎片 |
| 仅特定纸张卡纸 | 纸张太潮、太厚或类型错误 | 更换纸张 |
| 更换碳粉后卡纸 | 碳粉盒未正确安装 | 取出并重新牢固安装 |
| 反复在定影器卡纸 | 定影辊或压力垫磨损 | 更换定影器（维护套件） |
| 多张进纸（一次2张以上） | 静电堆积或分离垫磨损 | 将纸张扇形展开，更换分离垫 |
| 仅双面模式卡纸 | 双面通道辊子磨损 | 清洁/更换双面辊子 |

## 清除卡纸后

每次卡纸后始终执行以下步骤：

1. [ ] 所有盖子完全关闭并扣紧
2. [ ] 内部无残留碎纸（用手电筒检查）
3. [ ] 纸盒已牢固重新插入
4. [ ] 打印机显示"就绪"（无错误）
5. [ ] 测试页打印成功
6. [ ] 打印质量正常（无碳粉泄漏造成的条纹）
7. [ ] 在服务日志中记录卡纸（日期、位置、原因）
