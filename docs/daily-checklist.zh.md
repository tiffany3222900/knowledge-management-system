# 每日维护检查清单

## 概述

持续的每日和每周检查是预防打印机故障和保持打印质量最有效的方法。本清单应由指定的打印机操作员在每个工作日的开始和结束时执行。

---

## 每日早晨检查清单

在当天第一个打印任务之前执行以下任务。

### 1. 目视检查

- [ ] 打印机电源已开启，就绪指示灯为绿色常亮
- [ ] 控制面板显示屏无错误或警告消息
- [ ] 出纸托盘为空，可接收页面
- [ ] 预热期间无异常噪音（研磨、咔嗒、尖叫）
- [ ] 走纸通道周围无纸屑或异物
- [ ] 线缆连接牢固且无损坏

### 2. 纸张供应

- [ ] 纸盒已装入正确类型和尺寸的纸张
- [ ] 装纸前已将纸叠扇形展开以防止多张进纸
- [ ] 纸张导板已紧贴纸叠调整（不要太紧）
- [ ] 纸张量高于最低填充线
- [ ] 纸盒中无卷曲、褶皱或潮湿的纸张
- [ ] 纸张存放在阴凉干燥处（使用前保持原包装）

### 3. 耗材状态

- [ ] 碳粉 / 墨水余量高于20%（低于则订购更换件）
- [ ] 硒鼓单元寿命高于10%（接近结束则安排更换）
- [ ] 废粉盒未满
- [ ] 订书钉（如多功能装订器）已装入
- [ ] 现场有备用耗材

### 4. 打印质量测试

- [ ] 从控制面板打印测试页
- [ ] 测试页无条纹、污渍或褪色区域
- [ ] 正常阅读距离下文字清晰可辨
- [ ] 颜色准确（彩色打印机）
- [ ] 测试打印过程中无卡纸

!!! note "记录计数器读数"
    每天早上在服务日志中记录总页数（计数器读数）。这有助于追踪使用模式并安排预防性维护。

---

## 每日下班检查清单

在当天最后一个打印任务之后执行以下任务。

- [ ] 出纸托盘已清空并归档
- [ ] 打印队列中无待处理或卡住的任务
- [ ] 扫描台 / 自动输稿器无原始文档
- [ ] 打印机盖完全关闭
- [ ] 打印机周围工作区域整洁
- [ ] 节能模式已启用（或按策略关闭打印机）

---

## 每周检查清单

每周五（或每周最后一个工作日）执行以下任务。

### 清洁

- [ ] 用干燥或微湿的无绒布擦拭外壳
- [ ] 清洁扫描玻璃和自动输稿器进纸辊
- [ ] 用异丙醇清洁进纸辊
- [ ] 用压缩空气清除通风槽灰尘
- [ ] 用屏幕安全湿巾清洁控制面板显示屏

### 功能检查

- [ ] 打印配置 / 耗材状态页
- [ ] 验证所有纸盒被正确识别
- [ ] 测试扫描到邮件和扫描到文件夹功能（如适用）
- [ ] 测试双面（双面）打印
- [ ] 检查固件更新并安排安装
- [ ] 审查服务日志中的重复出现问题

---

## 每月检查清单

- [ ] 执行全面深度清洁（参见 [清洁与保养](cleaning.md)）
- [ ] 检查定影器单元是否有磨损或损坏（务必完全冷却）
- [ ] 检查并清洁转印带 / 转印辊
- [ ] 验证打印机IP地址和网络配置
- [ ] 审查使用统计数据并主动重新订购耗材
- [ ] 验证打印机在保修或服务合同范围内
- [ ] 更新资产库存记录

---

## 季度 / 预防性维护

- [ ] 更换定影器单元（如在维护套件计划内）
- [ ] 更换转印辊和搓纸辊（维护套件）
- [ ] 清洁或更换臭氧过滤器
- [ ] 按制造商规格润滑运动部件
- [ ] 从服务菜单运行完整诊断测试
- [ ] 校准颜色套准（彩色打印机）

!!! warning "仅限合格技术人员"
    定影器更换、转印带更换和内部润滑应由合格的服务技术人员执行。除非受过培训，否则不要尝试这些任务。

---

## 检查清单快速参考

| 频率 | 关键任务 | 预计时间 |
|------|----------|----------|
| **每日（上午）** | 目视检查、纸张、耗材、测试打印 | 5分钟 |
| **每日（下午）** | 清空托盘、清除队列、整理区域 | 3分钟 |
| **每周** | 外壳清洁、扫描仪清洁、功能测试 | 15分钟 |
| **每月** | 深度清洁、定影器检查、网络检查 | 30分钟 |
| **每季度** | 维护套件更换、完整诊断 | 60分钟（由技术人员） |

---

## 升级触发条件

如发生以下任何情况，请停止日常维护并升级至IT支持：

- 清洁后仍反复卡纸（每天超过2次）
- 更换碳粉和清洁后打印质量问题仍持续
- 异常气味（烧焦、臭氧）或烟雾
- 重启电源后仍不清除的重复错误代码
- 打印机或配件的物理损坏
- 无法在本地解决的网络连接问题
