# 打印机维护手册

**一份实用指南，帮助您保持办公打印机的可靠性、高效性和长久使用寿命。**

---

## 欢迎

本手册概述了办公打印机的日常操作、维护和故障排除的标准流程。持续遵循这些指南可以减少停机时间、延长硬件使用寿命、提升打印质量并降低总体拥有成本。每当添加或更换设备时，请查阅本手册，并将打印副本放置在共享打印机附近，以便操作员在没有网络访问的情况下进行查阅。

!!! info "适用对象"
    本手册面向 IT 支持人员、设施管理员和指定的打印机操作员。终端用户也可参考 **纸张处理** 和 **故障排除** 章节解决常见问题。

## 核心原则

1. **预防胜于补救** — 定期维护的成本远低于紧急维修。
2. **保持双手和机器清洁** — 在清洁内部部件之前，请关闭并拔掉打印机电源。
3. **使用认证耗材** — 第三方碳粉和纸张可能会损坏设备并使保修失效。
4. **记录每次操作** — 在服务日志中记录每次任务、计数器读数以及更换的任何部件，以便跟踪趋势。
5. **如有疑问，请升级处理** — 不要拆卸本手册未涵盖的组件。
