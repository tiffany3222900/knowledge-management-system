# 打印机维护手册

**一份实用指南，帮助您保持办公打印机的可靠性、高效性和长久使用寿命。**

---

## 欢迎

本手册为办公打印机的日常操作、维护和故障排除提供标准化流程。始终遵循这些指南有助于减少停机时间、延长硬件寿命、提高打印质量并降低总体拥有成本。

!!! info "适用对象"
    本文档面向 IT 支持人员、设施管理员和指定的打印机操作员。终端用户也可参考 **纸张处理** 和 **故障排除** 章节解决常见问题。

## 核心原则

1. **预防胜于补救** — 日常维护的成本远低于紧急维修。
2. **干净的手，干净的机器** — 内部清洁前务必关机并拔下电源。
3. **使用认证耗材** — 第三方碳粉和纸张可能造成损坏并使保修失效。
4. **记录每次操作** — 在服务日志中记录维护情况以便趋势分析。
5. **有疑问时，升级处理** — 不要拆卸超出本手册范围的组件。
