# 清洁与保养

## 概述

定期清洁可预防最常见的打印机问题：卡纸、打印条纹、进纸错误和组件过早磨损。本节涵盖从基础外壳擦拭到内部组件保养的所有清洁流程。

!!! danger "开始之前"
    1. 使用电源按钮**关闭**打印机。
    2. 从墙壁插座**拔下**电源线。
    3. **等待**至少30分钟让定影器完全冷却。
    4. 佩戴丁腈手套以避免皮肤油脂接触组件。
    5. 切勿用裸手触摸硒鼓（感光鼓）表面。

---

## 外部清洁

### 频率：每周

1. 关闭打印机并拔下电源。
2. 用**干燥**的无绒布擦拭外壳、控制面板和出纸托盘。
3. 对于顽固污渍，用清水或温和的非研磨性清洁剂稍微润湿布。
4. 用专用屏幕湿巾清洁控制面板触摸屏（触摸屏上不要用酒精）。
5. 用压缩空气吹扫通风槽（保持气罐直立，距离15厘米）。
6. 重新插电并开机。

!!! caution "切勿直接喷洒"
    切勿将清洁液直接喷洒到打印机上。始终先喷到布上，并确保布是微湿的，而非滴水状态。

---

## 扫描玻璃和自动输稿器清洁

### 频率：每周或扫描出现条纹时

### 平板扫描玻璃

1. 打开扫描仪盖。
2. 将少量玻璃清洁剂喷到无绒布上（不要直接喷在玻璃上）。
3. 以圆周运动擦拭玻璃，然后用干净布擦干抛光。
4. 在良好光线下检查 — 任何灰尘或污渍都会在扫描页面上显示为线条。
5. 同时清洁盖子内侧的白色参考条。

### 自动输稿器（ADF）

1. 打开自动输稿器盖。
2. 用异丙醇润湿无绒布。
3. 清洁自动输稿器进纸辊、分离垫和玻璃条。
4. 手动旋转辊子以清洁整个圆周。
5. 所有组件完全干燥（5分钟）后再关闭。

!!! tip "诊断技巧"
    如果扫描页面每次在同一位置出现垂直线，原因几乎总是自动输稿器玻璃条上的灰尘，而非平板玻璃。先清洁窄玻璃条。

---

## 进纸辊清洁

### 频率：每月或进纸错误增加时

脏的进纸辊是卡纸和多张进纸的首要原因。

1. 关机、拔下电源并打开纸盒。
2. 找到打印机内部、纸张上方的进纸辊。
3. 用异丙醇润湿无绒布或棉签。
4. 轻轻擦拭辊子表面，旋转以清洁所有面。
5. 如果辊子表面光滑或发亮（磨光），可能需要更换 — 联系IT支持。
6. 干燥5分钟。
7. 重新安装纸盒并打印测试页。

### 搓纸辊（第2纸盒及以上）

对每个纸盒的搓纸辊重复相同步骤。可能需要取出纸盒并向腔内观察才能接触到。

---

## 内部走纸通道清洁

### 频率：每月或清除严重卡纸后

1. 关机、拔下电源并等待30分钟让定影器冷却。
2. 打开前盖并取出碳粉 / 硒鼓单元。
3. 用压缩空气轻轻吹走走纸通道中的灰尘和纸屑。
    - 保持气罐直立，距离15-20厘米。
    - 使用短脉冲；长时间喷射可能导致气罐冻结。
4. 用酒精润湿的布擦拭可触及的橡胶辊。
5. 检查是否有之前卡纸留下的碎纸片。
6. 重新安装碳粉 / 硒鼓单元并关闭所有盖子。
7. 插电、开机并打印测试页。

!!! warning "请勿触摸"
    - **硒鼓单元表面** — 指纹会导致永久性打印缺陷
    - **定影辊** — 即使30分钟后仍可能温热
    - **转印带** — 极其脆弱；仅使用压缩空气，切勿触摸

---

## 碳粉 / 墨水泄漏清理

如果在更换碳粉盒时碳粉泄漏：

1. **不要使用标准吸尘器** — 碳粉细小且导电；可能损坏吸尘器并造成火灾风险。
2. 如有碳粉专用吸尘器（HEPA过滤、防静电）请使用。
3. 否则，用干燥的无绒布轻轻沾起粉末。
4. 对于残留灰尘，用微湿布（仅清水）。
5. 所有表面完全干燥后再关闭打印机。
6. 按当地法规处理受污染的布。

!!! danger "碳粉与高温"
    切勿对泄漏的碳粉使用热风鼓风机或热风枪。碳粉在约180°C时熔化，会永久粘结在表面上。

## 定影器区域清洁

### 频率：每季度（由合格人员执行）

定影器使用热量和压力将碳粉熔化到纸张上。需要小心处理。

1. 确保打印机关机并拔下电源至少30分钟。
2. 打开后部或侧部定影器检修盖。
3. 目视检查定影辊是否有碳粉堆积、划痕或磨损。
4. 用干燥的无绒布轻轻擦拭定影器入口和出口导板上的多余碳粉。
5. **不要**触摸热辊表面 — 它有涂层且容易损坏。
6. 关闭盖子并运行几张空白页以清除残留碳粉。

!!! warning "定影器更换"
    如果定影器出现可见划痕、薄膜撕裂或导致重复打印缺陷，必须更换。这是定期维护套件中包含的磨损件。

## 清洁计划汇总

| 组件 | 频率 | 方法 |
|------|------|------|
| 外壳 | 每周 | 干燥 / 微湿无绒布 |
| 扫描玻璃 | 每周 | 玻璃清洁剂 + 无绒布 |
| 自动输稿器辊 / 玻璃条 | 每周 | 异丙醇 |
| 进纸辊 | 每月 | 异丙醇，充分旋转 |
| 内部走纸通道 | 每月 | 压缩空气 + 布 |
| 定影器区域 | 每季度 | 干布，目视检查 |
| 通风槽 | 每周 | 压缩空气 |
| 控制面板 | 每周 | 屏幕安全湿巾 |

---

## 不应清洁的部件

| 组件 | 原因 |
|------|------|
| 硒鼓单元（感光鼓） | 指纹和光线会造成永久性损坏 |
| 转印带 | 极其脆弱；接触会造成划痕 |
| 定影热辊 | 涂层损坏；有烫伤风险 |
| 激光扫描单元 | 密封单元；打开会使保修失效并可能使激光错位 |
| 打印头（喷墨） | 仅使用制造商的喷头清洁工具 |
