# 安全指南

## 概述

打印机维护涉及电气、热、机械和化学危险。遵循这些安全指南可保护人员和设备。所有维护人员在执行本手册中的任何操作前必须阅读并理解本节。

---

## 一般安全原则

1. **有疑问时，停止。** 如果某个操作感觉不安全或超出您的培训范围，不要继续 — 升级给合格技术人员。
2. **一人一任务。** 不要在他人同时操作同一台打印机时进行维护。
3. **沟通。** 如果您正在维修打印机，请放置"暂停服务 — 维护进行中"标志，以免用户尝试使用。
4. **不走捷径。** 切勿绕过安全联锁或用胶带固定门开关以在盖子打开时操作打印机。
5. **急救。** 知道最近的急救箱、洗眼站和灭火器的位置。

## 电气安全

### 任何内部维护之前

- [ ] 使用电源按钮关闭打印机（不要在运行时直接拔插头）
- [ ] 从墙壁插座拔下电源线
- [ ] 如果打印机有独立电源开关，将其设为"关"
- [ ] 尝试开机以验证打印机已断开连接

### 电气危险

| 危险 | 风险 | 预防措施 |
|------|------|----------|
| 高压电源 | 电击、烧伤 | 切勿打开电源外壳；仅由合格人员维修 |
| 激光扫描单元 | 激光辐射可能损伤眼睛 | 不要打开激光扫描器盖；关闭时联锁可防止暴露 |
| 湿手 / 潮湿环境 | 增加电击风险 | 确保双手干燥；不要在电气组件附近用水 |
| 电源线损坏 | 电击、火灾 | 定期检查线缆；如有裂纹、磨损或挤压则更换 |
| 插座过载 | 火灾 | 使用专用插座；不要串联插线板 |

!!! danger "激光安全"
    激光打印机使用激光束在硒鼓上写入图像。切勿尝试解除门联锁开关或直视激光扫描组件。激光不可见且可能造成永久性眼损伤。

## 热安全

### 定影器单元

定影器是激光打印机中最热的组件，工作温度为 **180-220°C（356-428°F）**。

- 关机后**始终等待30分钟**再接触定影器区域。
- 即使30分钟后，定影器仍可能温热 — 谨慎触摸。
- 使用指定的把手或杆；切勿直接抓取定影辊。
- 如果闻到烧焦味或看到烟雾，立即关机、拔下电源，必要时疏散该区域。

### 其他热组件

- **转印辊** — 长时间打印运行后可能变热
- **双面器通道** — 通过的纸张可能烫手
- **喷墨打印头** — 某些喷墨打印机将打印头加热至40-60°C

### 烧伤急救

1. 立即移开热源。
2. 用凉（非冰）流动水冷却烧伤处10-20分钟。
3. 不要在严重烧伤处涂抹冰、黄油或药膏。
4. 用干净的不粘敷料覆盖。
5. 对于大于硬币的烧伤、起泡烧伤或面部/手部烧伤，请就医。

## 机械安全

### 夹点和运动部件

打印机包含齿轮、辊子、皮带和电机，可能夹伤手指或卷入首饰、头发或衣物。

- **切勿**在打印机开机运行时将手伸入。
- 维护前取下戒指、手表、手镯和悬挂首饰。
- 将长发扎起。
- 不要在运动部件附近穿宽松袖子或围巾。
- 使用提供的杆和把手 — 不要强行操作组件。

### 重物搬运

- 桌面打印机（20公斤以下）：用腿部力量抬起，不要用背部。
- 落地式 / 多功能打印机（20公斤以上）：**需要两人**或使用搬运车。
- 切勿通过出纸托盘、扫描仪盖或纸盒抬起打印机 — 这些不是结构件。
- 确保目标表面平坦、稳定并能承受重量。

## 化学安全

### 碳粉

碳粉是一种精细塑料粉末（聚酯或苯乙烯-丙烯酸酯）含颜料。虽然毒性不高，但需要小心处理。

| 危险 | 预防措施 |
|------|----------|
| 吸入细粉末 | 在通风良好的区域工作；避免产生粉尘云 |
| 皮肤刺激 | 佩戴丁腈手套；处理后洗手 |
| 眼睛刺激 | 处理大量泄漏时佩戴安全眼镜 |
| 衣物染色 | 穿实验服或围裙；碳粉污渍难以去除 |
| 空气中的火灾风险 | 使碳粉远离明火和高温源 |

### 碳粉泄漏应急处理

1. **不要使用标准吸尘器** — 它可能使粉末雾化并损坏吸尘器电机。
2. 如有碳粉专用HEPA吸尘器请使用。
3. 否则，用干燥的无绒布轻轻沾起粉末（不要擦拭 — 这会将其磨入）。
4. 对于残留灰尘，用微湿布（仅清水）。
5. 让表面完全干燥。
6. 将受污染材料作为电子废物处置，不要放入普通垃圾。

### 异丙醇

- 在通风良好的区域使用 — 蒸汽易燃。
- 远离明火和热源。
- 不要在定影器或电气触点附近喷洒。
- 储存在密封容器中，远离热源和阳光直射。
- 如溅到皮肤上，用肥皂和水清洗。
- 如接触眼睛，用水冲洗15分钟并就医。

### 清洁剂

- 仅使用本手册或制造商指南中指定的清洁剂。
- 切勿混合清洁产品（例如漂白剂 + 氨水 = 有毒氯胺气体）。
- 将所有清洁化学品保存在原标签容器中。
- 将易燃液体（异丙醇）储存在防火柜中。

## 个人防护装备（PPE）

### 所有维护必需

- [ ] **丁腈手套** — 用于处理碳粉、脏组件和化学品
- [ ] **安全眼镜** — 使用压缩空气或处理碳粉泄漏时
- [ ] **包趾鞋** — 在所有打印机房间

### 特定场景PPE

| 任务 | 额外PPE |
|------|---------|
| 定影器区域维护 | 耐热手套（冷却后）、长袖 |
| 大量碳粉泄漏 | N95防尘口罩、安全眼镜、手套 |
| 压缩空气清洁 | 安全眼镜（防尘/碎屑） |
| 搬运重型打印机 | 钢头鞋、腰部支撑带 |
| 肩部以上高度工作 | 阶梯凳（不是椅子或箱子） |

## 环境安全

### 通风

- 打印机房间应有足够的通风或HVAC。
- 激光打印机在运行期间会排放低浓度臭氧和超细颗粒。
- 对于高印量打印机（每月10,000页以上），考虑专用通风系统或带HEPA和活性炭的空气净化器。
- 不要将打印机放在小型不通风的壁橱中。

### 消防安全

- 使打印机距离易燃材料至少1米。
- 确保该区域可使用C类（电气）灭火器。
- 切勿对电气火灾用水 — 使用CO₂或干粉灭火器。
- 如果打印机着火：**如安全则拔下电源**，疏散，拨打紧急服务电话。

### 废物处置

| 废物 | 处置方法 |
|------|----------|
| 用过的碳粉盒 | 制造商回收计划（免费邮寄） |
| 废粉 | 密封在塑料袋中；电子废物设施 |
| 异丙醇容器 | 危险废物 / 化学品处置 |
| 沾有碳粉的清洁湿巾 | 电子废物或受污染废物 |
| 旧打印机 / 部件 | 电子废物回收（不要填埋 — 含重金属） |
| 纸张 | 标准纸张回收 |

## 应急程序

### 电击

1. 如果受害者仍接触电源，**不要触摸受害者**。
2. 在断路器处切断电源或拔下设备。
3. 立即拨打紧急服务电话。
4. 如果受害者无反应且无呼吸，如受过培训则开始CPR。
5. 除非受害者处于直接危险中，否则不要移动受害者。

### 火灾

1. 启动火灾警报。
2. 如安全则拔下打印机电源。
3. 使用C类灭火器（CO₂或干粉）— **切勿用水**。
4. 如果火势蔓延或无法控制，疏散并关门。
5. 拨打紧急服务电话。

### 碳粉入眼

1. 不要揉眼睛。
2. 立即用干净的温水冲洗至少15分钟，撑开眼睑。
3. 就医。

### 运动部件伤害

1. 立即关机并拔下打印机电源。
2. 不要试图用力取出被夹住的肢体 — 拆卸或求助。
3. 对割伤或瘀伤进行急救。
4. 对于挤压伤、深割伤或疑似骨折，就医。

在每台打印机附近张贴此清单：

- [ ] 打开盖子前关机并拔下电源
- [ ] 等待30分钟让定影器冷却
- [ ] 需要时佩戴手套和安全眼镜
- [ ] 电气组件附近无水或液体清洁剂
- [ ] 碳粉泄漏不用标准吸尘器
- [ ] 不要解除门联锁
- [ ] 保持区域无杂物和易燃物
- [ ] 报告所有事故和未遂事件
